Installation guide

  1. First, create the browser extension files (manifest, popup, and OCR/capture code).
  2. Package the files into a ZIP archive.
  3. Install it in a compatible desktop browser using its extension developer mode.
  4. Mobile Chrome on Android does not support installing regular Chrome extensions directly; use a compatible browser or a computer for testing.
